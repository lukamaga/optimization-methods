# Coursework attribution

This repository presents optimization coursework from Lukaš Patrik Magalinski's 2024 study archive at Vilnius University, Faculty of Mathematics and Informatics. The accompanying one-dimensional, unconstrained and nonlinear optimization reports identify him as their author.

The programs implement and adapt established numerical methods for course assignments. The archive also contains classroom examples and reference implementations; their complete upstream provenance is not recorded.

## Preserved source files

The six program files below retain the original bytes, including comments, function names, parameters and plotting behavior. Only their containing directories have been organized for this repository.

| Repository file | Original path within the `Optimizavimas` archive | Associated coursework |
| --- | --- | --- |
| `labs/one_dimensional/algorithms.py` | `vienmatis/algorithms.py` | One-dimensional optimization, September 2024 |
| `labs/one_dimensional/main.py` | `vienmatis/main.py` | One-dimensional optimization, September 2024 |
| `labs/unconstrained/optimization_algorithms.py` | `be_apribojimu/optimization_algorithms.py` | Unconstrained optimization, October 2024 |
| `labs/unconstrained/main.py` | `be_apribojimu/main.py` | Unconstrained optimization, October 2024 |
| `labs/constrained/main.py` | `neties_test/main.py` | Nonlinear box-volume optimization, November 2024 |
| `labs/linear/main.py` | `ties/tiesinis/main.py` | Linear-programming tableau implementation |

The constrained program was selected because its negative-volume objective, surface-area equality and nonnegative side lengths match the author's nonlinear-optimization report. The separate `netiesinis/main.py` uses a different quadratic objective and is not an alternative entry point for that same experiment.

## Supporting material

The published selection contains one program per laboratory topic and the associated author-owned illustrations and reports. Duplicate drafts, instructor handouts and other students' reports are excluded.

Original Lithuanian comments and figure labels are retained. English READMEs explain the mathematical models and how to use the preserved scripts. Source-specific notices, if present, remain part of the original files.
